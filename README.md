# CS-300_SNHU

# ABCU Advising Program Project Reflection

The purpose of this project was to provide students with a method of loading course data,
viewing the sorted list of courses, and look up individual courses and their prerequisites.

## What problem was I solving in these projects?

The main problem was figuring out how to store, organize, and retrieve course information efficiently. 
In Project One, this meant analyzing how different data structures perform in terms of runtime and memory. 
In Project Two, the problem shifted to building a working advising program that could load course data, sort it alphabetically, and retrieve individual course details on demand.

## How did I approach the problem?

I approached the problem by first learning how different data structures behave and what they are best used for. 
Project One helped me compare vectors, linked lists, and hash tables so I could understand their strengths and weaknesses. 
That knowledge carried over into Project Two, where I chose a hash table to allow fast lookups of course information. 
Understanding data structures is important because the right choice can make a program faster, easier to maintain, and more scalable.

## How did I overcome any roadblocks encountered while going through the activities or project?

One of the main challenges was making sure I followed the project requirements without taking shortcuts. 
Implementing a custom hash table instead of relying on built-in containers required more careful planning, 
especially when handling string-based course IDs and collision handling. I overcame this by breaking the program into smaller parts, 
testing each piece, and then combining everything once it was working correctly.

## How has my work on this project expanded your approach to designing software and developing programs?

These projects pushed me to think more about design before writing code. Instead of jumping straight into implementation, 
I spent more time planning how data would be stored, accessed, and modified. 
This made the overall program structure clearer and helped reduce issues later in development.

## How has my work on this project evolved the way I write programs that are maintainable, readable, and adaptable?

Working through both projects helped me become more consistent with organization, naming, and separating responsibilities within my code. 
I now pay more attention to writing code that is easier to read and modify, which makes it simpler to adapt when requirements change or when new features need to be added.
